FeedPak specification JSON Schemas, MIT License, Copyright (c) 2026 The feedpak

Python runtime dependencies: FastAPI, Uvicorn, python-multipart, PyYAML,
jsonschema (FeedBack installs it from requirements.txt). Optional verification
dependencies: pytest, Playwright/Chromium. These are supplied by the local
environment and are not copied into the plugin or source tree.

Standalone builds (tools/standalone.spec, built with PyInstaller) do bundle
PyInstaller's bootloader (GPL-2.0 with its bundling exception), the Python
interpreter with the native libraries it links to (such as OpenSSL, zlib, bzip2,
xz, libffi, mpdecimal and expat; the set varies by OS), the runtime dependencies
above with the packages they need, and PyGuitarPro. Each package's licence text
is in _internal/<package>.dist-info and Python's is in _internal/licenses/python;
Python lists the licences of the software it incorporates at
https://docs.python.org/3/license.html. PyGuitarPro is LGPL-3.0:
requirements-build.txt and tools/standalone.spec let you rebuild with a modified
copy. This program's source is at https://github.com/zagatozee/open-chart-editor.

They also bundle gp2rs.py, gp2rs_gpx.py, safepath.py, safe_xml.py and
notation.py from FeedBack (https://git.barlind.se/freedBack/feedBack),
AGPL-3.0-only, same license as this project: the Guitar Pro converters and
notation support, so those features work without a separate FeedBack install.
Pinned source commit and update instructions: tools/vendor/feedback-lib/README.txt.
A local FeedBack install, where present, is used in preference to this bundled
copy (see feedback_core() in pack_io.py). The external tools below stay external.

External tools, invoked and never bundled: FFmpeg; vgmstream for Wwise .wem
audio (from a local FeedBack/Slopsmith install or PATH); the DLC Builder
toolkit's ww2ogg/revorb; the FeedBack gp2rs/gp2rs_gpx Guitar Pro converters when
run against a local FeedBack install rather than the bundled copy above (run in
an isolated subprocess, PyGuitarPro for GP3-5); optionally a local gp-to-feedpak
checkout for import assistance. .NET SDK is an external tool.

Format interoperability: R+ (Rocksmith+) song folder XML, metadata.json and tone
references, and the R+ Workshop .rsw layout, were worked out to let this
independent editor open and write those formats. The repository contains
original code and format descriptions only: no decompiled code, game assets,
charts, audio or R+ Workshop project data. One R+ keyboard tone preset
identifier (grand piano) is included so written keyboard charts reference a
real preset. Chord-name rankings use counts measured over locally downloaded
charts; no chart content is included.

Rocksmith, Rocksmith+ and R+ are Ubisoft product names, used only to describe
compatibility. This is an independent authoring project; it does not claim
affiliation with Ubisoft or an official release.
